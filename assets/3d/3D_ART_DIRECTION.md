# 3D ART DIRECTION — CHROME SCULPTURE + ROCKS

## Конкретный образ

Один **абстрактный драгоценный арт-объект из 3 переплетённых хромированных лент**, плавная петлеобразная геометрия без острых случайных концов, сложные пересечения, изящные отверстия и естественное ощущение массы. Хром **не золотой**, холодное серебро с лёгкими синими отражениями. Стоит в правой части Hero, отбрасывает красивый силуэт в свете. Не копируйте в точности чужой логотип/скульптуру из референсов.

Графика вокруг: **7–12 асимметричных тёмно-графитовых камней** (низкополигональные/скульптурные детали), разнесены по оси Z. Камни должны работать на parallax и occlusion при scroll, не как метеоритный дождь. Большие foreground-камни частично вне кадра, дальние маленькие. Тонкие орбитальные линии — опциональная HTML/Three-декорация (не обязательны в самом GLB).

## Технические параметры итогового экспорта

- Два независимых ассета: `chrome_sculpture.glb` и `floating_rocks.glb` (или 1 сцена с группами/имёнными узлами).
- Центр скульптуры около `(0,0,0)`, оси glTF/Three.js совместимые. Диаметр скульптуры ориентировочно 3–4 world units.
- Материал Blender Principled BSDF: Metallic `1.0`, Roughness `0.09–0.18`, Base Color нейтральный серебристый. **Отражения обеспечиваются HDR environment и area lights на стороне сайта** — без environment чистый хром будет невнятно серым/чёрным.
- Геометрия: переплетение smooth bezier/sweep ribbon + аккуратная smooth shading, достаточно круглые блики, нет самопересечений-артефактов. Толщина ленты 0.2–0.4 относительно общей ширины 4.
- Rocks: цвет `#161A20` (варьировать), roughness `0.82–1`, metallic 0; irregular chipped edges, отдельные меши и имена для независимого parallax.
- Суммарный mesh бюджет подбирать по FPS (старт 30–90k tris для всей сцены при десктопном размере), мобильная облегчённая версия при необходимости.
- Финальный `.glb` по возможности < 3MB, compressed. Без встраивания огромных 8K текстур.
- Обязательно проверить материал в реальном Three.js Canvas при 1440×900 и 390×844, не ориентироваться только на рендер Blender.

## Что уже приложено

- `chrome_sculpture_STARTER.glb` — **реальный** GLB с тремя переплетёнными трубчатыми петлями, годится для первого интерактивного прототипа. Это **не** конечный арт-объект: у него менее изящная форма, чем у утверждённого изображения.
- `floating_rocks_STARTER.glb` — 9 простых мешей камней по глубине.
- `generate_starter_glb.py` — воспроизводимая генерация этих двух начальных GLB через `numpy` + `trimesh`.
- `blender_scene_generator.py` — альтернативный генератор в Blender с экспортом `.glb`; скрипт можно доработать вручную.
- `PROMPTS_FOR_AI_3D.md` — английский и русский промпты для генеративных 3D-сервисов.

## Рекомендуемый workflow: Blender (наиболее контролируемый)

1. Установить Blender версии 4.x или совместимой, открыть сцену, запустить `blender_scene_generator.py` во вкладке Scripting. Экспорт создаёт `chrome_sculpture_blender.glb` и `floating_rocks_blender.glb` рядом со скриптом.
2. Художественно исправить петли в Edit Mode/Curve Edit: добиться **широких плоских скульптурных лент**, а не обычных круглых шлангов, и композиции, близкой к `approved_hero.png`.
3. Отрегулировать массу/топологию, включить bevel, smooth normals; проверить пересечения без z-fighting.
4. Для веба — экспорт glTF 2.0/GLB, проверить на Three.js с `Environment`/HDRI и световыми полосами, оптимизировать.
5. В DOM пролетов использовать rotation/scale/depth, не запекать сложную анимацию скролла в GLB.

## AI-3D workflow: Tripo / Meshy / другой сервис с GLB

1. Использовать `PROMPTS_FOR_AI_3D.md`. По возможности добавить `approved_hero.png` как **visual style/shape reference**, но при экспорте убрать камни из самой модели скульптуры (отдельные ассеты).
2. Предпочтительно генерировать **скульптуру отдельно от камней**, иначе анимация параллакса станет невозможной.
3. Требовать экспорт `.glb/.gltf/.fbx`, проверять целостность mesh/UV/materials. AI часто производит сваренную безликую массу с неправильными отверстиями — это повод переделать, не оставлять.
4. Проверить лицензию сервиса и право использования ассета на публичном сайте. Нельзя переносить защищённый чужой 3D-объект без разрешения.
5. Из редактора Blender корректировать AI-меш и экспортировать веб-оптимизированный GLB.

## Жёсткие критерии внешнего вида

- Скульптура выглядит премиально, а не просто как 3 серебристых тора.
- Правильная масштабная иерархия: главная скульптура, несколько вторичных камней, крупный текст; не переполнить кадр.
- Весь объём существует в 3D и при движении курсора видна смена перспективы/отражений.
- Загрузка не делает Hero пустым: fallback заставка + transition to interactive.
- На мобильном нет перекрытия скульптурой текста и не падает FPS.
