# Image use rules — READ BEFORE WORKING

- `approved_hero.png`: **утверждённый пользователем** визуальный референс Hero. Именно его настроение (хром, камни, графит, свет) нужно воплотить как работающий сайт.
- `sculpture_visual_reference.png`: кадрирование той же **концепт-иллюстрации** для художника 3D, не готовый GLB.
- `desktop_composition_ONLY.png`: схема динамической desktop-композиции с небольшими карточками; **изображения внутри карточек придуманы генератором, не использовать как реальные проекты**.
- `mobile_stack_motion_ONLY.png`: **три состояния анимации** (две карточки перекрываются и предыдущая уменьшается). Интерфейсы карточек внутри тоже вымышленные.
- `scroll_storyboard_map.png`: схема очередности сцен для Codex.

**Снимки настоящих проектов НЕ ВХОДЯТ В АРХИВ.** Делать их на целевых сайтах через `scripts/capture_project_previews.mjs`.
