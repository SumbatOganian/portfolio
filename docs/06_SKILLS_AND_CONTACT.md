# 06. Навыки и контакты

## Навыки — только понятная художественная композиция

Показывать 5 парящих стеклянных chrome-капсул: **Python**, **Django**, **JavaScript**, **HTML / CSS**, **Git**. Расположить вокруг приглушенного каменного ядра или на орбитальных траекториях. `assets/references/desktop_composition_ONLY.png` показывает общую идею, но не является фактическим источником.

- Основная профессиональная цель: Python backend (Junior / Intern).
- Django: работа с веб-продуктом InviteCraft; не обещать квалификацию сверх уровня.
- JS/HTML/CSS/Git: подтверждены репозиториями статических сайтов.
- PostgreSQL **не показывать по умолчанию**: в данном пакете нет надёжного подтверждения самостоятельного использования.
- Иконки брать из официально разрешённых/открытых SVG (например, Simple Icons / Devicon с проверкой лицензии и атрибуции). Не вставлять картинки с непонятной лицензией.
- По hover/focus допускается одно короткое объяснение, но **без** рейтинга «95% Python», «expert», «5 лет опыта».
