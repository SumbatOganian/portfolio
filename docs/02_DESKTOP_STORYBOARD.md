# 02. Desktop: одно непрерывное пространство

## Общий принцип

Не пять секций с разными фонами, а **одна цифровая инсталляция**. На ширине >= 1024 px экран stage закрепляется (pin), а колесо/трекпад управляет анимационным временем камеры, 3D и DOM. Фон — чёрный графит с несколькими каменными фрагментами (передний, средний и задний планы). Скролл нативный и обратимый. Сцену делает скульптура/камни; текст/кликабельные карточки остаются в DOM.

## Разкадровка с относительным scroll-progress (ориентир)

**0–15% — Hero / Arrival**
- Мягкое начальное движение скульптуры, заголовок «ИДЕИ. КОД. РЕЗУЛЬТАТ.» слева, подзаголовок «Создаю веб-приложения и сайты с вниманием к дизайну, логике и реальным результатам».
- Скульптура ~40–48% ширины на правой половине. Очень яркие **холодные** отражения на ребрах. Не навязчивая анимация от курсора, инерция 0.1–0.2.
- Камни рассредоточены на 3 глубинах; передний слегка размытый, задний мало заметен.
- Чёткие ссылки/кнопки в DOM: Смотреть проекты, GitHub.

**15–35% — Reveal / emergence**
- Заголовок плавно поднимается/растворяется построчно, скульптура начинает удаляться по Z, небольшая rotation.
- Первая мини-карточка InviteCraft **реально визуально выходит из-за скульптуры** (контролируемая окклюзия/слой): сначала частично скрыта объектом, потом пересекает его границу и вылетает вперед.
- Затем из глубины одна за другой Verdi, Pulse, Tochka Sborki, Povodinvite. Не анимировать все одновременно.
- Возле карточек только названия, стрелки, тонкое холодное обрамление. Без описаний.

**35–74% — Spatial Gallery / arch**
- 5 небольших прямоугольников на дуге. Видно ~3 карточки в фокусе, остальные по краям дальше/меньше; движения мягкие, без резкого перекручивания.
- Прокрутка перемещает фокус по дуге от первого проекта к пятому. Карточки немного поворачиваются так, чтобы их интерфейс оставался читаемым. По желанию лёгкий hover tilt (не больше 4°), lift +8–14 px, brightness. Нажатие открывает внешний URL.
- Скульптура уменьшается и становится вторичным элементом фона, **не закрывает** клики по карточкам.
- Камни проходят перед/за компонентами с разной скоростью, но не перекрывают интерактивные области.
- Недопустимо делать стандартную широкую сетку 2×3 или список с длинными описаниями.

**74–91% — Skills constellation**
- Карточки отлетают назад в сторону/в глубину. Персонаж-скульптура может стать темным силуэтом или частично вернуться.
- Пять стеклянно-хромированных капсул с логотипами и названиями технологий: Python, Django, JavaScript, HTML/CSS, Git. Расставить как орбитальную композицию, с сильным отрицательным пространством.
- Небольшой заголовок «КЛЮЧЕВЫЕ НАВЫКИ»; на hover/focus — краткая подсказка без выдуманного опыта. Не показывать PostgreSQL без подтверждения.

**91–100% — Contact closing**
- Сцена затихает; скульптура может ещё раз мягко проявиться меньшего размера. Минимум контактов внизу/сбоку: GitHub, Email/Telegram только если известны, «Резюме» только если файл существует.
- Нет отдельного рекламного гигантского блока «Готов к новым проектам».

## Контрольная механика

- Один master GSAP ScrollTrigger с `scrub: ~0.4–0.8`, `pin: stage`, длительность ориентировочно 450–650vh (подбирается по реальному ощущению). Скролл должен идти в обе стороны.
- Состояние 3D привязано к `timeline.progress()`, а не к независимому `setInterval`.
- `useFrame` — только для плавной инерции/вращения, без React setState каждый кадр.
- Навигация и якоря: Hero / Projects / Skills / Contact и программный скролл к progress диапазонам, без блокировок скролла.
- Если бесшовная real 3D occlusion карточек слишком тяжела: используйте DOM layers + маску с правильным перспективным визуальным результатом; **не** подменяйте всю картину одним растровым постером.

## Дизайн карточки

Соотношение ~1.35–1.7 по ширине, скругление 10–16px (в масштабе композиции), холодная серебристая рамка 1px, тень, изображение настоящего сайта 100% площади, поверх снизу аккуратный градиент для подписи. Название в нижнем левом углу; круглая стрелка в правом. Никаких описаний. Клик/фокус срабатывают независимо от движений сцены.
