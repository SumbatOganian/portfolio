Данные для рендера: `data/projects.json`. Скриншоты **не приложены**: во время подготовки ZIP удалённый браузер не смог открыть публичные сайты. Нельзя использовать UI из генераций в качестве «настоящих скриншотов».

## Что считать качественным превью

- Это **реальный снимок hero/первого экрана опубликованной страницы** после загрузки шрифтов и изображений.
- Не фотография ноутбука на столе, не рисованный интерфейс, не Photoshop/AI mockup.
- Desktop 1440×900 или 1600×1000, PNG/WebP (лучше PNG master + оптимизированный WebP), как минимум 2x для большой карточки.
- Снять и мобильную версию 390×844 для дополнительного режима/если обрезка desktop неудачна.
- Сайты различаются по стилистике, их **не перекрашивать** под общий фон. Общую эстетику задаёт рамка карточки, а не вмешательство в скриншот.
- Использовать `object-fit: cover`/`object-position`, при сложных hero можно хранить `focalPoint` для индивидуального кадрирования.
- Не включать cookie overlay, прелоадер, браузерные панели и артефакты анимаций.

## Захват: реальный Chromium через Playwright

Из папки проекта Codex:

```bash
npm install --save-dev playwright
npx playwright install chromium
node scripts/capture_project_previews.mjs
node scripts/verify_previews.mjs
```

Скрипт сохраняет `public/project-previews/<id>-desktop.png` и `public/project-previews/<id>-mobile.png`, если URL доступен. Если ошибка сети — не создаёт поддельный файл и выводит явный FAIL. Codex должен самостоятельно исправить техническую проблему окружения или запросить пользовательские снимки только после попыток браузерного захвата.

## Проблемные случаи

- У InviteCraft большой эмоциональный интерфейс и открываемые шаблоны. На карточке основной снимок **самой главной страницы**; в портфолио **не** добавлять отдельные страницы шаблонов.
- У Verdi главное сообщение сайта — «Мебель, которая живет дольше поколений». Не заменять визуал на выдуманную мебельную витрину из прежних AI-картинок.
- У Pulse на hero текст «Разрабатываем IT-продукты, которые приносят доход с первого месяца» — это **контент самого сайта**, не заявленное достижение владельца портфолио; допустимо видеть внутри реального screenshot, но не повторять как факт в описании портфолио.
- У Tochka Sborki hero — «ТОЧКА СБОРКИ» / «собери себя в IT», есть курсы IT, Python, UX/UI и характерная графика; не рисовать спортивные товары или обувь.
- У Povodinvite начало «Приглашение, которое хочется открыть». Внешний вид из оригинального сайта, без косметической генерации другой флористики.
