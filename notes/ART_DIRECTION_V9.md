# Версия 9 — SO по центру

Последнее уточнение пользователя: S слева, O справа, обе буквы по центру экрана. Монограмма теперь расположена горизонтально и центрирована по двум осям фотографии. Размер отдельных букв, подъём снизу белым и переход в непрерывно меняющееся цветовое поле после остановки фото сохранены.

Вместо прежнего запаса около 1 px по верхнему краю Canvas-маски оставлено 8 px сверху и снизу. Это защищает контуры от подрезания и артефактов масштабирования. Шрифт — Roboto Flex Variable, вес 300; окончательный контур рассчитан по реальным метрикам букв.

Проверки: npm run build; qa/v9/results.json, настольный Chrome на ширинах 320/390/1440/1920 и WebKit iPhone. Проверяется прозрачный запас в реальных пикселях маски, центрирование, белый вход и движение цвета. Скриншоты — qa/v9/. Запуск: npm run qa:monogram при работающем production preview, либо QA_BASE_URL=http://127.0.0.1:5173 npm run qa:monogram для dev-сервера.

Остальной интерфейс из версии 8 сохранён. Предыдущие художественные изменения описаны в ART_DIRECTION_V8.md и ART_DIRECTION_V7.md.
