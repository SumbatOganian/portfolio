# Версия 18 — портрет приближается верхним краем

По уточнению пользователя инвертирован только наклон rotateX в приближении: верхняя часть кадра ближе к зрителю, нижняя уходит назад. Амплитуда 14°, остальные движения и масштаб прежние. В полноэкранном состоянии фото выравнивается.

Проверки: npm run build и фактическая DOMMatrix-геометрия в Chrome 1440×900 / 390×844: Z верхнего края больше Z нижнего, после раскрытия наклон равен нулю. Кадры и значения — qa/v18/. Набор текста, окрашивание подложки и горизонтальный финал из версии 17 сохранены.
