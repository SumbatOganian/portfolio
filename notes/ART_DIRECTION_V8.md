# Версия 8 — первые кадры проектов и выход из навыков

Изменения по последнему сообщению пользователя:

- До нажатия Preview внутри каждой карточки виден первый кадр реального сайта из ранее захваченных desktopPreview. Полная длинная страница загружается только после включения Preview; пока она загружается, первый кадр остаётся видимым. Отключение Preview возвращает первый кадр и сбрасывает прокрутку.
- Название возвращено вниз стеклянной карточки, за пределы демонстрационного экрана. Оно сохраняет белый цвет в обоих состояниях. Светлая подложка и смена цвета удалены. Единственная внешняя ссылка по-прежнему стрелка справа внизу.
- Чёрная штора на выходе из навыков сохранена. Прежде навыки затухали и смещались вниз. Теперь после начала подъёма шторы весь контент навыков, навигация этапов и нижняя строка слегка и медленно поднимаются вверх. Прозрачность остаётся единичной. Когда sticky-сцена заканчивается, следующий экран естественно выталкивает прежнюю секцию вверх. Обратный скролл восстанавливает положение.
- Портрет, личный текст и финал из версии 7 сохранены. При отключённой анимации весь контент остаётся в обычном потоке.

Проверки и видео — qa/v8/. npm run qa проверяет карточки и новый переход в Chrome desktop/mobile, reduced motion и WebKit iPhone. npm run qa:portrait содержит предыдущие проверки портрета. Браузерная эмуляция не заменяет физические устройства.
