# Версия 17 — цвет появляется вместе с набирающимся текстом

- При приближении и раскрытии портрета обе стороны подложки остаются серыми: цветная область полностью закрыта.
- Во время набора текста справа постепенно открывается живая цветная подложка. Используется тот же прогресс, что и для числа напечатанных букв. Открытие рассчитано по фактической ширине видимого правого поля: половине текста соответствует половина цветной полосы. Цвет не заполняет поле раньше времени за непрозрачной фотографией.
- При полном наборе подложка справа целиком цветная; после паузы сохранён прежний горизонтальный переход к финалу. При обратном скролле цвет закрывается вместе со стиранием текста. Левый блюр не меняется.
- Цветовое поле не сдвигает сам портрет и не меняет геометрию текста. Его рисунок остаётся непрерывным с финалом. В режиме без анимации показано статическое законченное состояние.

Проверки: npm run build; npm run qa:colour. Сравниваются реальные пиксели видимой правой полосы при 0/25/50/75/100% набора; левая остаётся монохромной. Проверены обратный скролл, финальный переход, мобильная последовательность, reduced motion и WebKit. Кадры, результаты и видео — qa/v17/.
