# DIGITAL MATTER

Портфолио веб-разработчика Sumbat Oganian: frontend / backend. React + TypeScript + Vite, Three.js, GSAP ScrollTrigger. Статическая сборка без backend.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Dev: http://127.0.0.1:5173/ . Production preview: http://127.0.0.1:4173/ . Для тестов нужен установленный Google Chrome; для проверки WebKit и записи видео: `npx playwright install webkit ffmpeg`.

## Текущая версия 19

Крупная хромированная сцена переходит в навыки и чёрный фон. Буквы личного текста собираются уже при появлении секции в viewport; к её началу текст выровнен. «ВСЕГДА В ДВИЖЕНИИ» набрано крупными прописными; каждое следующее предложение разделено на две ступенчатые строки. Затем портрет приближается верхним краем к зрителю, нижним в глубину, и выравнивается в широком полноэкранном кадре. Во время раскрытия фото подложка с обеих сторон серая. По мере набора биографии цветное поле открывается справа: доля окрашенной видимой полосы соответствует прогрессу печати. К последним буквам правая сторона становится полностью цветной, а левая сохраняет серый блюр. На фотографии нет инициалов. После полного раскрытия фото слева появляется мигающий курсор. Дальнейшая прокрутка печатает заголовок «Интерес стал делом.» и короткую биографию: давний интерес к веб-разработке, начало в 30 лет и обучение в IT-академии, желание развиваться и создавать полезные продукты. На телефоне текст занимает нижнюю часть кадра, сохраняя лицо открытым. Прокрутка назад стирает текст; строки и колонка остаются на месте. После полного набора есть пауза для чтения перед движением вправо. При reduced motion сразу показан весь текст без курсора. Контент хранится в `data/site-config.json`, поле `about`.

В шапке только белый SO слева и белая навигация справа; на телефоне меню открывается правой кнопкой. Шапка остаётся белой на всех экранах, цветная заливка полностью отменена. Для полного контура O добавлен небольшой правый запас; gap пунктов на desktop — 22 px. При наведении и клавиатурном фокусе буквы пункта быстро меняются местами и возвращаются за 220 мс; ширина слова не меняется, подсветки нет.

После раскрытия фото дальнейший скролл перемещает сцену вправо: портрет уходит влево, а финал въезжает справа на той же высоте. Подложка и финал образуют непрерывную цветовую панораму. При уходе в финал набранные буквы последовательно сереют с конца к началу. По правому видимому краю самого снимка проходит мягкая волна инверсии; она охватывает часть фото, сохраняя остальную область исходной. Обратный скролл восстанавливает цвета букв и фото; «Контакты» ведут прямо в финал. Иконки связи выровнены по центру под именем, стрелка — справа в той же строке.

В каждой карточке до включения Preview показан реальный первый экран сайта. Preview включает прокрутку полной страницы внутри того же экрана. Название постоянно расположено внизу стеклянной карточки, вне демонстрационного экрана, белым текстом без подложки. Внешний сайт открывается только стрелкой. Полный реальный снимок сайта автоматически прокручивается в небольшом встроенном окне; есть пауза. Модального окна и блокировки страницы нет. Навыки показаны цветными иконками без всплывающих текстов. На выходе сначала поднимается чёрный фон, затем иконки, заголовок и элементы навигации медленно смещаются вверх без затухания. При входе следующей секции прежний экран продолжает уходить вверх с естественным движением страницы. Пять навыков дополнительно поднимаются с разной скоростью, слегка дрейфуют вбок и поворачиваются; после выхода sticky-сцены они уходят немного быстрее обычного скролла. В покое сохраняется лёгкое независимое покачивание.

## Контент и источники

- `data/site-config.json`: имя, текст, подтверждённые соцсети.
- `data/projects.json`: пять проектов и точные ссылки.
- `data/skills.json`: навыки без рейтингов опыта.
- `public/project-scrolls/manifest.json`: HTTP-статусы, размеры и время реального браузерного захвата полных страниц.
- `public/portrait/sumbat-original.webp`: предоставленная пользователем фотография, нормализован EXIF-поворот, без перерисовки лица.
- `public/models/`: оригинальная процедурная геометрия; отражение Studio Small 09 (Poly Haven, CC0) и текстуры хранятся локально.
- `notes/THIRD_PARTY_LICENSES.md`: лицензии. Текущие шрифты — Roboto Flex Variable, SIL OFL.

## Проверки

При работающем production preview:

```sh
npm run qa
npm run qa:finale
npm run qa:header
npm run qa:motion
npm run review:about
npm run qa:typing
npm run qa:colour
npm run qa:exit
npm run review
npm run capture:full
```

`qa/v19/` — текущая волна инверсии, посерение букв с конца, обратимость, проверки пикселей и видео. `qa/v18/` — наклон фото верхним краем вперёд. `qa/v17/` — последовательность серой и цветной подложки, проверенная по пикселям, и видеозапись. `qa/v16/` — набор от скролла: курсор, частичный и полный текст, обратное стирание, стабильная вёрстка, reduced motion, WebKit и видео. `qa/v15/` — предыдущий статичный вариант биографии. `qa/v14/` — проверки и записи движения навыков и shuffle меню. `qa/v13/` — снимки и проверки полного контура логотипа, постоянной белой заливки, более плотной навигации и отсутствия инициалов на фото. `qa/v12/` — предыдущая цветная версия шапки. `qa/v11/` — горизонтальный переход, навигация, обратный скролл, reduced motion, WebKit и видеозаписи. `qa/v10/` и более ранние папки относятся к предыдущим вариантам. `qa/v8/` — проверки карточек и перехода от навыков, снимки и видео. Проверки портрета и типографики сохранены в `qa/v7/`. Старые qa/v2, qa/v3, qa/v4 относятся к предыдущим вариантам. Подробности текущего направления: `notes/ART_DIRECTION_V19.md`.

Включены reduced motion, ручное отключение анимации, WebGL fallback, статическая версия портрета, клавиатурный фокус и встроенный Preview. Рендер 3D и цветового поля останавливается вне viewport / в скрытой вкладке. Полные изображения проектов загружаются при открытии Preview.

Физические iPhone / Android и полевые Web Vitals не измерялись; браузерная эмуляция не заменяет эти проверки.

## Публикация

`dist/` подходит для статического размещения в корне домена (Vercel / Cloudflare Pages: build `npm run build`, output `dist`). Для подпапки GitHub Pages нужно согласовать абсолютные URL ассетов с base path. Публикация не выполнялась.

Исходное техническое задание сохранено в `CODEX_START_HERE.md`, `docs/`, `assets/`. Более поздние указания пользователя из `notes/ART_DIRECTION_V19.md` имеют приоритет над первоначальными художественными ограничениями.
