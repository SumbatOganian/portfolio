# Версия 5

- Preview теперь расположен внутри соответствующей карточки: повторное нажатие выключает его. Нет dialog, затемнения страницы, блокировки скролла или захвата фокуса. Реальные полные снимки продолжают автоматически прокручиваться, доступна пауза.
- Подсказки навыков удалены из DOM. Иконки окрашены: Python — синий, Django — зелёный, JavaScript — жёлтый, HTML/CSS — оранжевый, Git — красный.
- Перестановка букв управляется входом секции в viewport (top 80% → top top), поэтому на момент выравнивания секции текст уже собран. Далее начинается приближение фото и испарение символов.
- Портрет получает перспективный наклон rotateX / rotateY во время приближения; к полноэкранному состоянию наклон обнуляется, чтобы кадр оставался ровным и без щелей.
- Фон финала заменён на непрерывное вычисляемое цветовое поле с искажением координат. Изображение пересчитывается примерно 30 раз в секунду, без видео, конечной точки и пауз при видимом экране. В скрытой вкладке и вне viewport рендер экономит ресурсы; reduced motion сохраняет статический вариант.
- Иконки выровнены по центру под именем, стрелка — на той же горизонтали справа. Размер имени и основная композиция сохранены.

Проверки и актуальные снимки: qa/v5/. Повторный запуск: npm run build, npm run preview, npm run qa. Прошлые qa/v4 и ранее относятся к предыдущим решениям.
