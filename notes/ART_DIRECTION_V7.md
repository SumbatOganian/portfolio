# Версия 7 — уточнение портрета и личного текста

Последние указания пользователя имеют приоритет над исходным брифом. Карточки, Hero и финальный экран сохранены из версии 6.

- «ВСЕГДА В ДВИЖЕНИИ» — крупный заголовок прописными в верхней части экрана. Три последующих предложения разделены на две явные строки каждое и смещены ступенями. На ширинах от 320 до 1920 px половины предложений не переносятся дополнительно.
- Инициалы используют Roboto Flex Variable — тот же шрифт, что и имя в финале. Более тонкие высокие S и O расположены вертикально вплотную, в правом нижнем углу. Сначала S, затем O медленно поднимаются снизу белыми. После раскрытия фотографии на весь экран белый цвет плавно сменяется живым цветовым полем финала. При прокрутке назад последовательность обратима.
- Фото на desktop использует contain для всего верхнего кропа, вместо cover с приближением к лицу; по бокам лежит затемнённая размытая копия оригинала. На mobile используется полный исходный портрет. Дополнительного увеличения самого изображения нет; растёт только рамка фотографии.
- Лицо и исходный снимок не перерисовывались. Цвет букв рисуется Canvas2D, без видео. Рисование останавливается вне видимости и в скрытой вкладке. При reduced motion буквы и фото неподвижны.

Проверки: npm run build, npm run qa (Chrome 320/390/768/1440/1920, WebKit iPhone, reduced motion, последовательность белых букв и финальный цвет). Результаты и снимки — qa/v7/. Это браузерная эмуляция, не проверка на физических устройствах.
