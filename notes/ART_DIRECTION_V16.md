# Версия 16 — биография печатается от прокрутки

- Текст биографии и его расположение сохранены. Сначала полностью раскрывается портрет. После этого слева появляется ОБО МНЕ и мигающий текстовый курсор. Дальнейшая прокрутка последовательно печатает заголовок и оба абзаца, всего 233 символа. При обратном скролле они стираются в обратном порядке.
- Строки зарезервированы целиком, а символы включаются по одному через opacity. Поэтому слова переносятся одинаково на всех стадиях набора, колонка не сдвигается и не перекрывает лицо. Курсор вычисляет положение по последнему набранному символу и меняет высоту между заголовком и основным текстом.
- Трек прокрутки увеличен, чтобы сохранить прежнее расстояние приближения и добавить участок набора. Фото заканчивает приближаться к прогрессу .432; курсор проявляется с .435; набор идёт с .46 до .79; после паузы движение вправо начинается с .85. Приближение сохраняет прежний темп, горизонтальный переход по-прежнему занимает около 120vh прокрутки.
- Полный текст доступен скринридеру однократно, без посимвольных live-объявлений. При reduced motion / отключении анимации весь текст сразу виден, курсор скрыт.

Проверки: npm run build; npm run qa:typing. Chrome desktop/mobile: курсор после полноэкранного кадра, правильный префикс текста на промежуточной позиции, полный набор до начала горизонтального перехода, стирание назад, неизменные размеры колонки и положение курсора. Ширины 320–1920, горизонтальная ориентация, reduced motion и WebKit iPhone. Снимки, результаты и видео — qa/v16/.

npm run review:about теперь снимает полностью набранное состояние. qa:finale обновлён под начало перехода .85 и середину .925. Остальные эффекты и белая шапка сохранены.
