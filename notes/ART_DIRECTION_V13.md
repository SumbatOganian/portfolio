# Версия 13 — белая шапка и целая O

- Полностью отменены цветная заливка шапки, анимация градиента и управление её цветом из скролл-сцены. SO, пункты меню и линии мобильной кнопки постоянно белые.
- Причина среза O — background-clip:text в блоке автоматической ширины с отрицательным letter-spacing: часть крайнего контура выходила за область заливки. Теперь текст рисуется обычным способом, overflow видимый, добавлено 5 px справа и безопасная высота строки. Шрифт и плотность SO сохранены.
- Gap навигации на desktop уменьшен с 40 до 22 px. Вертикальное мобильное меню сохраняет плотное расположение без дополнительных промежутков.
- Положение шапки, отсутствие SO на фото и все прежние переходы сохранены.

Проверки: npm run build; npm run qa:header. Проверяются реальный запас пикселей справа от полного контура логотипа, белый цвет на Hero / портрете / финале, отсутствие переливания, навигация к контактам и мобильное меню. Снимки Chrome и WebKit, результаты — qa/v13/.
