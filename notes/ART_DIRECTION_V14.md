# Версия 14 — невесомость навыков и shuffle навигации

- Сохранён прежний подъём чёрного фона и общий уход секции вверх без затухания. Поверх него каждый из пяти навыков имеет собственную скорость подъёма, небольшой боковой дрейф и поворот. Когда начинается обычный выход секции за viewport, дополнительный подъём продолжается пропорционально прокрутке: элементы движутся чуть быстрее страницы. Без прокрутки остаётся слабое независимое покачивание.
- Движение не отменяет существующие повороты и hover стеклянных карточек: используются отдельные CSS translate и rotate. GSAP ticker останавливает обновления вне видимой сцены и в скрытой вкладке. При отключённой анимации inline-перемещения сбрасываются.
- В шапке добавлен shuffle при наведении мыши и клавиатурном фокусе. Сами буквы перемещаются между двумя перестановками и возвращаются на места за 220 мс. Ширина слова и доступное имя ссылки постоянны. Цвет всегда белый; подсветки нет. Touch не запускает лишнюю hover-анимацию, reduced motion полностью отключает shuffle.

Ориентир: https://www.art-yakushev.com/info — осмотрены элементы навигации с text-split / text-shuffle и отдельными char. В нашем интерфейсе используется собственная реализация на Web Animations API, без копирования кода сайта.

Проверки: npm run build; npm run qa:motion. Chrome desktop/mobile: различающиеся траектории вверх, покачивание, дополнительная скорость на выходе, обратная прокрутка, 220 мс shuffle без скачка ширины, reduced motion. WebKit iPhone: CSS translate/rotate и переход по контактам. Результаты, снимки и видео — qa/v14/.
