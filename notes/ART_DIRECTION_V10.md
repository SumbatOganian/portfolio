# Версия 10 — нижнее SO и двухцветная подложка портрета

- SO смещены к нижнему краю фотографии и остаются по центру горизонтали. Размер, плотность набора, последовательное белое появление и переход к живому цвету сохранены. Учтён нижний safe-area inset; контуры не подрезаются.
- За фотографией слева сохранена исходная размытая серая копия. Справа добавлено такое же непрерывное Canvas2D-поле, как в финальном экране. Оно уже анимируется во время раскрытия рамки, а не запускается только в конце. Центральный снимок остаётся поверх подложки.
- При reduced motion подложка использует неподвижную заливку, как финал. В скрытой вкладке и вне viewport рисование останавливается.

Проверки: npm run build; QA_BASE_URL=http://127.0.0.1:5173 npm run qa:monogram; node scripts/check-portrait-underlay.mjs. В последней проверке сравниваются реальные участки двух кадров во время увеличения фото: левая часть остаётся неизменной, правая меняется. Снимки и результаты — qa/v10/.

Предыдущие решения описаны в ART_DIRECTION_V9.md и ART_DIRECTION_V8.md. Карточки, навыки, текст и финал не изменялись.
