# Версия 11 — движение вправо к финалу

Последний участок прокрутки теперь ведёт вправо. После завершения прежнего приближения фото оно уходит влево; с правой стороны в том же закреплённом viewport раскрывается финальный цветной экран с именем и контактами. Вертикальное движение в остальных частях страницы сохранено.

- Портрет и финал расположены в общем двухэкранном ряду. Сначала идёт прежняя последовательность текста, фотографии и SO; последние 20% прогресса управляют горизонтальным перемещением. Высота трека увеличена, чтобы сохранить расстояние прокрутки прежнего приближения.
- Правая подложка и финал показывают соседние фрагменты одной цветовой панорамы с одинаковым временем анимации. На стыке нет резкой смены рисунка или цвета.
- Обратная прокрутка возвращает портрет. «Контакты» сразу прокручивают к полностью открытому финалу; стрелка наверх работает в прежнем режиме. Пока финал за краем экрана, его ссылки исключены из фокуса через inert.
- При reduced motion / отключённой анимации финал остаётся в обычном вертикальном потоке. Устранён конфликт мобильной фиксированной высоты со статической секцией, который оставлял лишнее пространство.

Проверки: npm run build; npm run qa:finale (по умолчанию dev 5173, либо QA_BASE_URL для другого сервера). Chrome 1440×900 / 390×844: геометрия без вертикального смещения, нативное колесо, обратный скролл, Контакты, стрелка вверх, отсутствие горизонтального overflow. Отдельно reduced motion и WebKit iPhone. Сравниваются пиксели по обе стороны цветового стыка. Снимки, результаты и видео — qa/v11/.

Все решения по карточкам, навыкам, тексту и SO из предыдущих версий сохранены.
